Setup Firebase Diperlukan

API Firestore belum diaktifkan atau konfigurasi belum benar.

Ikuti langkah-langkah berikut:

  1. Buka Firebase Console
  2. Pilih project kamu → Firestore Database → Buat database
  3. Buka Authentication → aktifkan Email/Password
  4. Pastikan konfigurasi Firebase sudah benar

Setelah setup, refresh halaman.
